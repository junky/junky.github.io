JS Parser Tests

Each test file is loaded twice: from this site and from the original site. Both copies are run and what they report is compared. Open this page on a localized domain to test how the proxy translates JavaScript files.

The last three files test chunk boundaries inside closing JSON markers. Where the chunks of a response end changes from request to request, so run them several times.
